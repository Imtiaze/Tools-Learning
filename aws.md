# AWS Fundementals

## 1. Introduction To AWS [Day1]


- Amazon is the biggest ecommerce provider in the world
- It's reliable trustworthy and their tech is trustworthy
- In 2000- 2005 Amazon created a platform to help their Engineers to focus more on writing softwares and less on managing the infrastructure in which the software runs.
- In 2006 Amazon open this platform to public and introduced two services.
> Simple Storage Service (S3)
> Elastic Compute Cloud (EC2)

This platform is known as the AWS / Amazon Web Service

- The AWS allows to host infrastructure in various geopgraphical locations or regions
- Infrastructure should be in the regionc closest to the application user, which will reduce the Latency and make the application respond faster to the user
